# Event Management System

A Java-based Event Management System developed as part of the Advanced Object Oriented Programming course (PA3) at LaSalle College Montréal — Winter 2026.

## Project Description

This system allows organizers to create events and participants to register for them. It is built incrementally over four iterations following Agile development practices and MVC architecture.
